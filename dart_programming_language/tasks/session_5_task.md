# Dart Loops Tasks

## 🟢 Task 1 — While Loop

Use a `while` loop to:

- Print the numbers from **1 to 100**
- Calculate and print their **sum**

### Expected Output

```text
1
2
3
...
100
Sum = 5050
```

---

## 🟡 Task 2 — Even Numbers + Continue

Use a `for` loop to print the numbers from **1 to 50**.

Requirements:

- If the number is **odd**, use `continue` to skip it.
- Print only the even numbers.
- Don't use another loop or a list.

### Expected Output

```text
2
4
6
8
...
50
```

---

## 🟠 Task 3 — Finding a Number + Break

Create the following variable:

```dart
int secretNumber = 7;
```

Use a `while` loop starting from `1` and check the numbers one by one until you reach the secret number.

Requirements:

- Print every number you check.
- When you reach `7`, print `"Found!"`
- Use `break` to stop the loop.

### Expected Output

```text
Checking 1
Checking 2
Checking 3
Checking 4
Checking 5
Checking 6
Checking 7
Found!
```

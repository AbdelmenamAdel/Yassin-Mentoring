## How to push to github at the first time in steps: 

- echo "# Test-GitHub" >> README.md
- git init
- git add README.md
- git commit -m "first commit"
- git branch -M main
- git remote add origin https://github.com/AbdelmenamAdel/Test-GitHub.git
- git push -u origin main
